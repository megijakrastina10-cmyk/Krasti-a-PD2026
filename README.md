
# Ceļojumu projekts — PD2026

## Par projektu
Šis projekts ir izveidots programmēšanas darba ietvaros.
Tā ir tīmekļa vietne par ceļojumiem un skaistām vietām pasaulē.

## Izmantotās tehnoloģijas
- HTML — mājaslapas struktūra.
- CSS — dizains, krāsas un animācijas.
- Attēli — ceļojumu galamērķu attēlošanai.

## Veiktās izmaiņas
1. Izveidota HTML struktūra ar navigāciju un sadaļām.
2. Pievienoti CSS stili un animācijas.
3. Pievienoti attēli un galamērķu kartītes.
4. Izveidots README.md faila apraksts.

## Failu apraksts
- `index.html` — mājaslapas struktūra.
- `style.css` — mājaslapas dizains un animācijas.
- `README.md` — projekta apraksts.
- `.gitignore` — norāda failus, kurus Git nedrīkst iekļaut versiju kontrolē.

## Projekta palaišana
1. Atver projekta mapi Visual Studio Code.
2. Atver failu `index.html`.
3. Palaid to pārlūkprogrammā.
